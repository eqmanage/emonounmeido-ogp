# 15秒プロモ動画(縦型ショート)

TikTok / Instagram リール / YouTube ショート / X 向けの 1080x1920・30fps・15秒動画。

- 完成品: `out/emonounmeido_15s.mp4`
- サムネイル: `out/cover.png`(フック画面)

## 構成

| 秒 | 内容 | 狙い |
|---|---|---|
| 0–2.5 | 「このまま 20年、働きますか？」+ 年齢が45→65歳へ進むカウンター | 最初の1秒で自分ごと化させるフック |
| 2.5–9.5 | 看護師→キャリアカウンセラー など、職業が「翻訳」される連打(徐々に加速) | 意外性で視聴を継続させる |
| 9.5–12.3 | 「あなたの経験は、何に翻訳される？」+ 結果カードのスロット→「？」 | 答えを見せず、続きは自分で診断したくさせる |
| 12.3–15 | えもの運命堂・診断ボタン・「3分・無料・登録不要」 | 行動喚起(CTA) |

翻訳例は本サイト(`js/app.js` の職業辞書)の実際の診断結果から抜粋。BGM・効果音は `audio.mjs` で合成しているため著作権の心配はありません。

## 再生成

```bash
./promo/build.sh   # node(Playwright) と ffmpeg が必要
```

文言やタイミングは `video.html`(映像)と `audio.mjs`(音のキュー)を編集。

## 投稿文の例

> このまま20年、働きますか？
> あなたの経験は、意外な仕事に「翻訳」できるかもしれません。
> 3分・無料・登録不要の可能性診断はプロフィールのリンクから。
>
> #40代 #キャリア #転職 #セカンドキャリア #適職診断 #可能性診断
